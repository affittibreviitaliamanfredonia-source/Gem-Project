# Glossario

| Termine | Significato nel progetto GEM |
|---|---|
| **Capofila** | Il soggetto spagnolo che aggrega i partecipanti e commissiona il servizio. È l'unica controparte contrattuale. |
| **B2B** | Il rapporto è tra due imprese. Gli ospiti non sono clienti diretti. |
| **Reverse charge** | Meccanismo per cui l'IVA è assolta dal committente nel suo paese, non dal prestatore. La fattura italiana è emessa **senza IVA**. |
| **Art. 7-ter** | Art. 7-ter DPR 633/1972: i servizi B2B si considerano territorialmente rilevanti nel paese del committente. Base normativa del reverse charge qui applicato. |
| **VIES** | Banca dati UE per la verifica dei numeri VAT intracomunitari. Un VAT non attivo a VIES fa decadere il reverse charge. |
| **Tranche 80 %** | Primo pagamento, dovuto all'**arrivo** degli ospiti. |
| **Tranche 20 %** | Saldo, dovuto alla **partenza** e **subordinato al controllo documentale**. |
| **Controllo documentale** | Verifica, a fine soggiorno, che la documentazione richiesta sia completa e conforme. È la condizione sospensiva del saldo 20 %. |
| **Costi variabili** | Costi che scalano col numero di ospiti: alloggio, transfert, mobility. |
| **Alloggio** | Costo della camera singola per ospite per l'intero periodo. |
| **Transfert** | Trasporti da/per aeroporto o stazione all'arrivo e alla partenza. |
| **Mobility** | Spostamenti locali durante il soggiorno (abbonamenti, navette, trasporti interni). |
| **Margine residuo** | `Ricavi incassati − Costi variabili sostenuti`. È la base della ripartizione 50/50. |
| **Saldo progressivo** | Colonna del file Excel: cassa cumulata dopo ogni movimento. |
