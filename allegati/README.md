# Allegati

Documenti ricevuti o prodotti: PDF, scansioni, contratti firmati, verifiche VIES,
preventivi, fatture.

## Convenzione di denominazione

```
AAAA-MM-GG-tipo-descrizione.estensione
```

Esempi:

```
2026-09-20-vies-verifica-capofila.pdf
2026-09-25-contratto-bozza-v1.pdf
2026-10-01-preventivo-alloggio-struttura-a.pdf
2026-10-15-fattura-001-tranche-80.pdf
```

## Dati personali

I documenti contenenti **dati personali degli ospiti** vanno in `allegati/privati/`,
cartella **esclusa dal versionamento** tramite `.gitignore`. Non committare elenchi
nominativi, copie di documenti d'identità o dati sanitari.
