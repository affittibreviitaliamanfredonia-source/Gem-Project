# 05 · Log delle decisioni

Storico **cronologico e immutabile**. Ogni decisione rilevante genera un file nuovo.

## Regole

1. **Un file per decisione.** Nome: `AAAA-MM-GG-titolo-breve.md`.
2. **Non si modificano i file passati.** Se una decisione viene superata, si crea un
   **nuovo** file che la sostituisce e si aggiorna il campo `Sostituisce:` / `Sostituita da:`.
3. **Si scrive anche quando si decide di non decidere** — un rinvio è una decisione,
   con le sue conseguenze.
4. Dopo ogni nuova voce, **aggiornare il [README principale](../README.md)** se lo stato cambia.

Modello: [`../templates/template-decisione.md`](../templates/template-decisione.md)
